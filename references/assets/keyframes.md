# 按需关键帧

默认不做关键帧，直接用多参考图生视频。只给下面这些镜头做首帧：
- 构图或站位必须精确，文字说不清；
- 人物身份容易漂移，需要先锁一张；
- 道具状态、手部持物必须精确；
- 跨时代或跨世界的形状匹配切；
- 用户点名要首帧。

产出为单独的关键帧清单，按镜号排列，文件开头写明对应哪一版分镜。不往已锁定的分镜文件里写，所以做关键帧不算改分镜。

## 1. 单帧只冻结一个瞬间
- 写这个瞬间人物已经在做什么，不写过程。
- 分镜里这一镜后面才发生的动作，不在首帧里提前完成。

## 2. 首帧提示词字段（全中文）
- 镜号和这一帧在镜头里的时间位置（起始 / 中间 / 结尾）。
- 地点；人物在世界里的位置、朝向、视线目标。
- 这一刻唯一的定格动作；道具的准确状态（在哪只手、开或合）。
- 机位高度和位置、朝向；景别；前景 / 中景 / 背景的安排。
- 身份依据：哪张人物板。地点依据：哪张空景母版（用本镜自己的机位，不照搬母版视角）。
- 光：光源和它在人身上的可见效果。质感：沿用第 3 步概念中的世界与美术设定的全局定调及本段局部视觉规则，局部规则仅在其明确范围内覆盖。
- 画幅；必须看清的部位。

## 3. 复杂调度先画草图
动作复杂、文字说不清时，先出一张俯视调度草图：人物起止位置、路线、机位、视线。草图只管空间，不管画面风格。

同场换机位或道具接触易错时，读 [asset-to-scene.md](asset-to-scene.md) 第 2–5 节；草图、空景母版、普通参考与真实首帧分别标职责，不能互相冒充。

## 4. 交付前核对
- 首帧和分镜里的首帧描述一致。
- 没有提前完成后面的动作。
- 用到的人物板、空景母版都写了编号。
