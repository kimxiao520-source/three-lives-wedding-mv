# 物理与光照设计参考

本页供照片资产查询受光和材质；写人物板与衣装时主要读第三节，场景读第二、三节，精确持物按需读第六节。静态图只描写选定瞬间，运动示例用于理解受力与受光，不把整段动作写进单张图。视频词沿用[第 9 步](../../steps/09-video-prompt.md)，不由本页另建格式。

## 一、全身动力学链
下面四层是检查清单，按动作挑需要控制的层来写，不必每个动作写满四层。动作简单、或某一层在画面里看不到时就省掉。
1. **主动部位**：做核心动作的身体部位。
2. **稳定部位**：维持平衡的部位（重心腿、核心）。
3. **联动部位**：跟着主动部位自然配合（肩跟着转、手臂跟着摆）。
4. **不自主反应**：呼吸、眨眼、重心微移、衣料随动。

示例（写全时的样子，实际按需删减）：
- **转头看对方**：颈部向右转；双脚不动，重心微移到左脚；右肩跟着转一点，下巴微抬；呼吸不变，眨眼一次。
- **牵起对方的手**：右手指尖先碰到对方手背，再滑进掌心握住；双脚站定，膝盖微屈；肩膀跟着前送，躯干微倾；握住时呼吸停一下再放出。
- **走路**：一脚前迈，后脚蹬地，核心收紧；对侧手臂前摆，躯干微前倾；裙摆和头纱随步伐后摆。
- **站着不动**：重心在一只脚，另一只脚微外撇；双手位置写明（垂在身侧 / 交握在身前 / 一手提裙摆）；胸口随呼吸起伏，自然眨眼，身体有极轻的晃动。

## 二、光照 – 表面交互
下面各项是检查清单，按镜头挑画面里看得清、需要控制的来写（例如特写写阴影和反射光，远景只写主光方向），不必每人写满。
1. 主光从哪来（窗光从左侧 / 夕阳从背后 / 烛光从右下方）。
2. 主光照到身体哪些部位。
3. 反射光从哪来（白色婚纱、地面、墙面把光反到下巴和颈部）。
4. 阴影落在哪（鼻影落在左脸 / 眉骨在眼窝投下阴影）。
5. 多光源时皮肤上的冷暖分区（头顶偏冷、侧脸偏暖、下颌偏暗）。
6. 轮廓光的来源（逆光在发丝和肩线勾出一圈亮边）。
7. 深色物体与暗部：黑西装、黑发、深色道具在暗处保留一层来自真实光源的轮廓光或边缘高光，暗部仍有细腻层次，不糊成一块死黑。

同场先固定光源在实际空间中的位置、色温和明暗基准，再按本镜机位与人物朝向写受光。反打时画面里的光向可以变化，不把“光源一致”写成所有镜头都从画面左侧照来；人物转头、走入阴影会合理改变脸部明暗。需要时对照肤色、白衣高光和暗部层次，避免无因曝光跳变，不锁死每镜同一亮度。

跨段沿用第 3 步已选的局部美术与光色：可以换世界、时段和冷暖，仍核对身份、材质与人物可读性。冷暖关系由光源、环境和创作意图共同决定，不规定升温必变暖、紧张必变冷，也不把整片套成一种色调。

## 三、婚礼常见材质的受光写法

| 材质 | 写法 |
|---|---|
| 缎面婚纱 | 顺着褶皱出现柔和的高光带，高光随身体转动沿褶皱滑动；褶皱凹处偏暗，暗部仍有细腻层次 |
| 蕾丝 | 光从镂空透过，花纹在皮肤上投下细碎的影子；蕾丝外沿在逆光下发亮 |
| 薄纱 / 头纱 | 半透明，逆光下整体透亮发光；层叠处更白更密，单层处能透出后面的发丝和肩线；随风或走动时外沿飘起 |
| 珍珠 | 柔和的圆形光泽，每颗有一个小而软的高光点，不刺眼 |
| 金饰（耳坠、项链、发冠、刺绣金线） | 细小而锐利的高光点，带暖色反射；人物移动时高光闪动、位置随之变化；金线刺绣在侧光下凸起处亮、凹处暗 |
| 红色礼服 | 正面受光处饱和，转折处变深；红色会向下巴和颈部反一点暖色 |
| 西装 | 羊毛面料吸光、哑光，翻领缎面处有一条窄高光；白衬衫领口把光反到下颌；深色西装在暗处用主光或环境光勾一条轮廓边，暗部保留层次 |
| 肤色 | 保留人物原有肤色；受光面通透，暗部偏暖；逆光时耳廓和指尖外沿透出暖红；白婚纱的反光让下巴和颈部更亮 |

## 四、环境动态候选
风吹头纱或发丝；树叶晃动；花瓣飘落；水面波光；烛火摇动；窗帘被风鼓起；尘粒在光束里浮动；远处行人或鸟飞过；呼出的白气（冷天）；茶或热汤升起的蒸汽。

随情绪节拍变化（可选，每镜最多一项）：写清在哪个动作或接触时变、怎么变。例如两人的手碰到时，风把头纱吹起；抬头对视时，云移开，阳光落到两人脸上；安静停住时，烛火由摇动变稳。

## 五、接触面物理
脚踩草地时草叶被压弯；裙摆拖过地面带起花瓣；手扶栏杆时手指受力微压；靠在对方肩上时衣料被压出褶皱。

## 六、有方向的物件
镜子、信 / 婚书 / 誓言卡、戒指盒、相框、手机、书这类有正反面或开口的物件，只写“拿着”时，模型常把正面转向镜头。按需挑下面几项写清：
1. 物件的正面或开口朝向谁。
2. 人物视线落在物件哪里。
3. 手怎么拿：哪只手，托底还是捏边。
4. 镜头看到的是哪一面：正面 / 背面 / 侧边。

示例：
- **戒指盒**：新娘双手托着打开的戒指盒，盒口朝向新郎；镜头在新娘身侧，看到盒子侧边和戒指的一角。
- **信 / 誓言卡**：新郎双手捏着卡片两边，字面朝向自己，视线落在卡片上；镜头在他身前，看到卡片背面。
- **梳妆镜**：新娘坐在镜前，镜头在她右后方，镜中映出她的脸和身后的房间。

## 七、画面层次（可选检查）
本镜需要时自问：前景有没有可读物件或遮挡？中景人物是否清楚？背景有没有地标或纵深？空气里有没有一点动态（尘粒、薄雾、花瓣）？不必四层都写进提示词；画面发空时先判断主体位置、空间任务与有意留白，再决定是否补前景或真实存在的环境变化（见第 11 步），不固定加尘粒、薄雾或花瓣。
