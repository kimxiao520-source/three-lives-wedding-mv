# 03 概念

输入：片型、观看线、已选年代与新人需求。先确定整片的画面基准，再设计每一世。

**整体美术基准**用可见特征描述：皮肤保留多少细节、画面明暗对比、是否添加颗粒、写实程度、装饰与人物的主次。按这次作品选择，不预设复古色、柔光或某种滤镜。各世可以改变光色，但皮肤、衣料和画面精细程度应协调。

每世填写一张世界卡：

| 字段 | 要写清什么 |
| --- | --- |
| 年代与地点 | 具体时代、主要空间，例如明代大宅庭院 |
| 季节与时段 | 季节、天气、白昼或夜晚 |
| 人物与关系 | 两人的身份、已经如何相处，角色是否知道其他世的事 |
| 情绪与贡献 | 本世最主要的感受，为整片增加哪一种相处内容 |
| 色彩与照明 | 主色、光从哪里来、脸和手如何照亮 |
| 空间与美术 | 主要建筑或陈设、人物活动区域、近处遮挡和远处地标 |

如希望制作更容易，可选择少雨或无雨的场面；雨景并非禁用。夜景可安排实际可理解的灯光，让面部与手部动作仍然清楚。

信物可选，不是跨世成立的前提。选凤簪时明确各世由谁佩戴、谁持有；选一人一半的玉佩时，记录哪半属于谁、何时靠拢、最后是否合成完整轮廓。区分同一件物品、不同年代的对应物和单纯形状呼应。

交付：整体美术基准、各世世界卡、信物状态简表（选用时）。复核每世的时代差异是否可见，是否仍围绕同一对人的观看线。
