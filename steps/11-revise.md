# 11 返修

输入：用户反馈、具体画面及连续性问题清单。先说明实际哪里不成立，再找到原因所在的层级。

用户只说“僵硬”“拖”“不对”时，先检查被指出的实际内容，判断是过程过长、回应缺失、动作关系错误还是构图妨碍观看，给出具体修改并在本轮范围内落实。确实无法定位时才问对应段落，不要求用户先学会专业术语。不在没有看到素材时猜测其缺陷；只有剧本就检查剧本。

| 层级 | 常见问题 | 优先处理 |
| --- | --- | --- |
| 概念 | 不知道全片要让人关注什么 | 重写观看线及各世贡献，保留已明确的选择 |
| 分场 | 内容反复、顺序散乱或容量不足 | 合并重复段，补真正有效的内容 |
| 剧本 | 关键行为缺少触发或回应 | 修正相应行为链及后续承接 |
| 资产 | 脸、服装、场地或信物结构错误 | 局部修对应图片，核对引用它的镜头 |
| 表演 | 反应机械或景别看不见情绪 | 简化动作，调整接收方的可见回应 |
| 分镜 | 空间不清或观看对象总不变化 | 修相关机位、景别或镜头顺序 |
| 视频词 | 图号错、起点冲突或一镜动作太多 | 改对应语句或拆分生成组 |
| 连续性 | 换脸、换手、方向或信物状态跳变 | 找兼容片段；缺少必要行为才补对应镜头 |

先尝试已有素材的可用区间和剪点。能改一句说明解决的输入问题，不扩大成整套图重做；必须补拍时只生成缺少的镜头，并重新检查相关接点。文字改好不等于旧视频的问题已经消失。

转场如果需要人物移动、真实接触或物体改变，就生成相应行为。缺少的动作不能用白闪、叠化或图形动画假装完成。原有画面已经完成行为时，可以按整片风格进行正常剪辑。

整理合格片段后，实际试听音乐，按乐句与人物行为调整剪点，添加需要的字幕和声音；删去无信息起尾，保护必要回应，不机械地每拍切一次。没有音频时明确声音尚待完成。

导出后完整正常播放并试听，检查重复收尾、突兀切换、闪帧、字幕遮脸、音量变化和结尾余音，同时核对文件能否正常打开及是否符合约定画幅、长度。修正后复看受影响部分；若剪辑或声音结构改变，再通看全片。

交付可播放文件及简短说明：修了什么、实际检查了什么、尚有哪些未完成项。只有文字或图片时就交对应成果，不宣称影片已完成；最终观感由用户看过实际影片后确认。
