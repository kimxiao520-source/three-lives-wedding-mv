# 09 视频词

输入：已选身份、衣装、场地和道具图，以及镜头表。采用多参考图生视频，先核对工具实际支持的图片数量和生成长度，按能力安排一镜一条或多镜一条。

按真实上传顺序分配图片职责。例如：图一新娘身份，图二新郎身份，图三本世双人衣装，图四庭院空景，图五凤簪外形。图片不得错号；同一张图承担两项职责时明确说明。

首帧状态只用文字描述，不额外制作起幅图片。写清站位、身体朝向、头部角度、视线和左右手持物，让起点能够接着完成本镜动作。已经握稳的起点不能再要求首次牵手。

一条提交词先写共用的人物、年代、光线与画面质感，再按镜号写起点、行为、回应、摄影和结束状态。共用要求在本条内只写一次；拆成不同提交时，每条都须带齐自己的图片职责与必要共用要求，不能用“同上”代替。

## 日常动作链

动作写成“主动部位 → 身体平衡 → 衣料或发丝随动 → 对方回应”。先说哪里开始动，再说明重心或支撑如何维持，补与动作相称的自然随动，最后让对方接收这次行为。保持站稳也是平衡，不强迫每次抬手都迈步；没有明显随动时不用凭空加风。

例如：“他先抬起右前臂，双脚站稳，袖口随抬臂向腕后轻滑；她看向他的掌心，抬起左手靠近。”这是一条连续因果，不是同时播放四个互不相关的动作。本公开版不编写奇幻大动作。

## 接触写到稳定完成

牵手、戴簪和递玉佩都必须交代谁的哪只手、接触位置、何时握稳或固定、对方如何接受。按实际服装和站位调整下列例子，不能只写“自然牵手”或“完成交接”。

| 接触 | 可执行写法 |
| --- | --- |
| 牵手 | 他右手掌心向上伸到她左手下方；她将左手放入他的掌心并轻收手指，他感到她的回握后才合拢右手；两手稳定相握后再起步 |
| 戴簪 | 他右手握簪身，将簪尖对准她发髻侧面的插入位置；她左手扶稳发髻、头部保持不动，待簪沿发髻插妥并固定，他才松指撤回右手，她随后放下左手、抬眼回应 |
| 递玉佩 | 他右手托住玉佩下缘，移到她摊开的左掌上；她左掌承住重量，右手拇指与食指轻扶玉佩两侧，持稳后他才撤开右手，她看清玉佩再抬眼看他 |

保持身体支撑与重心合理，袖口、发丝随实际动作轻动。接触前后不要换手、穿透或让物品悬空；结束状态必须给下一镜留出明确的持物与站位关系。

## 提交格式

可直接改填的格式：

> 图片分工：图一……；图二……；图三……。  
> 共用设定：本条发生在……；两人使用对应身份和衣装；光从……方向照入，脸部层次清楚，皮肤与织物保持自然纹理。  
> 镜头一：……景别，机位位于……。开始时……。随后……，对方……。相机……。结束时……。  
> 镜头二（需要时）：切到……，本镜改用……图中的场地或造型；开始……，随后……，结束……。

按镜组织，不按秒逐段叙述；时间点仅在需要指定镜内切点、对口型或精确接触瞬间时使用。以描述目标为主，必要时加少量针对性限制，例如“凤簪在这组镜头中保持佩戴在她发间”。视频词全部使用中文。

交付可以独立提交的完整词和对应图片清单。检查图与词是否冲突、动作是否超出生成长度、多镜是否各有明确起点。输入限制无法容纳时拆小生成组；多参考与文字起点不保证构图被精确锁定，结果仍需实际观看。
