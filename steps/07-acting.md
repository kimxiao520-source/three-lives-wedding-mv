# 07 表演

输入：剧本中的人物关系、动作与回应。先按计划中的画面单元写表演，分镜确定后归入对应镜号。

每个人物镜选择一至两个能被看见的细微反应。远景用停步、转身或身体距离变化；近景才写眉眼、嘴角、呼吸和手指。无人环境镜不硬加人物反应。

把情绪转成具体变化。例如“她被打动”可改成“她先看他，再缓缓松开抓住衣袖的手”；不要把皱眉、红眼、流泪、微笑同时塞进一个短镜头。

## 情绪变成可见动作

下表是可选写法，不是表情与情绪的一一对应。先看人物处境，每镜取一至两个有效变化，不把整行全部叠加。

| 情绪 | 可见动作示例 |
| --- | --- |
| 期待 | 目光停在对方将出现的位置，吸气后稍作停顿 |
| 紧张 | 手指拢紧袖口，嘴唇轻抿后又松开 |
| 害羞 | 视线短暂落下，再抬眼确认对方是否还在看自己 |
| 惊喜 | 眼睛稍稍睁大，原本抬起的手停在半途 |
| 犹豫 | 手伸出一小段又停住，目光从对方脸上转向那只手 |
| 安心 | 呼气变长，肩膀落下，握紧的手逐渐放松 |
| 心疼 | 眉心微收，手靠近对方后放轻接触力度 |
| 被打动 | 眼眶渐湿，嘴角松开，停住片刻才回应 |
| 信任 | 主动把手交入对方掌心，身体自然靠近 |
| 不舍 | 松手后指尖稍留，身体已转向而目光仍停在对方身上 |

## 部位粒度

把抽象感受落到画面能辨认的部位；细微动作需要相应景别，不因写得细就要求模型全部执行。

| 部位 | 可直接选用的写法 |
| --- | --- |
| 眉 | 眉心短暂收紧；眉梢轻抬后回落；紧绷的眉间慢慢舒展 |
| 眼 | 目光从手移到对方脸上；抬眼后停住；视线垂下又重新迎上 |
| 嘴 | 轻抿的嘴唇松开；一侧嘴角先扬起；欲言又止地微张嘴唇 |
| 呼吸 | 吸气后短暂停住；缓缓呼出一口气；呼吸从急促逐渐放稳 |
| 手 | 指尖轻拢袖边；掌心翻开等待接触；握稳后手指稍稍放松 |

## 行动与回应

事件镜写出触发、行动、接收方回应和结束状态。关系行为如果没有可见回应，观众就无法确认它是否被接受。回应可以留在同镜，也可交给相邻镜，但不能只存在于创作说明里。安静肖像和既有亲密状态无需硬补事件。

| 画面单元 | 触发与行动 | 接收方的可见变化 | 结束状态 |
| --- | --- | --- | --- |
| 明代庭院佩簪 | 他戴好凤簪，收回手后看向她 | 她抬眼停住，扶发的手自然放下 | 凤簪留在她发间，两人视线相接 |

安排对话或双人动作时，给听者、接收方足够画面，避免只有说话者或主动者。无对白作品不新增口型；不让两人毫无缘由地同时眨眼、转头或露出相同笑容。

日常动作按“主动部位 → 身体平衡 → 衣料或发丝随动 → 对方回应”写成因果链。例如他先抬右前臂，重心留在双脚之间，袖口随抬臂轻滑；她看见伸来的手后抬起左手回应。随动随动作强度发生，不能人物静止而衣摆和头发持续大幅飘动。

牵手、戴簪、递玉佩等接触必须说明：谁的哪只手、碰到哪里、何时握稳或固定、对方怎么接受。两人交接物品时，接收者承托稳定后递出者才松手；戴簪则在簪已固定、对方头部稳定后撤手。本公开版只处理日常行为与关系接触，不编写奇幻大动作。

表演按发生顺序描述，不逐秒编排。交付逐镜表演备注，检查所选景别能否看见这些变化，以及切镜后是否保留前一动作带来的情绪。
