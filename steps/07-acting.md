# 07 表演

## 1. 输入与停点

必需输入：本场剧本、人物起始关系、事件触发与结果、已定对白或无对白要求，以及涉及接触的道具状态。初写表演可按画面单元编号，分镜确定后对应到镜号，不要求先完成分镜。

不清楚人物在回应什么、接触如何完成或本场结束在哪里时，停该单元并退回剧本。涉及动作的服装或道具结构未知时，停对应接触设计并补齐资产设定。不能用自行添加的哭泣、微笑或台词掩盖输入缺口。

## 2. 判断与执行

### 先对齐本场内容

从剧本摘出内容编号、本单元在做的事、为什么此刻行动、必须留下的结果，再设计身体反应。抒情段可以表现已成立的配合习惯，不必反复演“初次被打动”；剧情段要表现听到或看到信息之后的态度变化，不提前笑出来泄掉选择。

把情绪词删掉再读表演卡：仍应看懂人在完成什么。若只剩抬眼、呼吸、微笑，无法说明共同活动或事件发展，退回第 5 步；若三世活动本身相同，退回第 3 步。不要给空情节增加更多身体细节。

### 从触发到余波

先写人物看见或听见什么，再写其改变的部位。事件应有“察觉 → 行动或接受 → 稳定结果”，回应可在同镜或下一镜，必须有明确承接；安静肖像可直接呈现已成立的关系，不强制再演一次相认。

每个人物镜选一至两个主要可见反应。远景用距离、停步、转身与肩背变化，近景再用眼神、嘴角与呼吸；无人镜不写人物反应。反应出现应晚于触发，切镜后保留上一行为的情绪余波，不让两人无缘由同步转头或同时笑。

### 事件镜与状态镜

先给每个单元定类型。事件镜：有新信息或接触改变关系，写全“触发 → 反应 → 可见选择”，选择须落在动作上（接受、停手、靠近、让开）。状态镜：安静并坐、保持微笑、一起观礼等已成立的关系，可停在持续注视、距离保持或余韵上，不要求新选择；仍保留呼吸、视线等细小反应，但不为凑数硬加转头、伸手。

### 情绪 → 可见动作

下表是可选写法。先依据处境选动作，不能把每种情绪固定为某张表情，也不把整行一次塞入短镜。

| 情绪 | 可见动作 |
| --- | --- |
| 期待 | 目光停在对方将出现的位置，吸气后稍作停顿 |
| 紧张 | 手指拢紧袖口，轻抿的嘴唇短暂松开 |
| 害羞 | 视线落下，又抬眼确认对方是否仍在看自己 |
| 惊喜 | 眼睛稍稍睁大，抬到半途的手停住 |
| 犹豫 | 手伸出一小段后停下，目光由对方脸上移向那只手 |
| 安心 | 呼气变长，肩膀落下，握紧的手逐渐放松 |
| 心疼 | 眉心微收，靠近对方的手在接触时减轻力度 |
| 被打动 | 眼眶渐湿，嘴角松开，停住片刻才回应 |
| 信任 | 主动将手交入对方掌心，身体自然靠近 |
| 不舍 | 松手后指尖稍留，身体转向而目光仍停在对方身上 |

### 部位粒度

| 部位 | 三种可选写法 |
| --- | --- |
| 眉 | 眉心短暂收紧；眉梢轻抬后回落；紧绷的眉间慢慢舒展 |
| 眼 | 目光从手移到对方脸上；抬眼后停住；视线垂下又重新迎上 |
| 嘴 | 轻抿的嘴唇松开；一侧嘴角先扬起；欲言又止地微张嘴唇 |
| 呼吸 | 吸气后短暂停住；缓缓呼出一口气；呼吸由急促逐渐放稳 |
| 手 | 指尖轻拢袖边；掌心翻开等待接触；握稳后手指稍稍放松 |

### 日常动作与接触

按“主动部位 → 身体平衡 → 衣料或发丝随动 → 对方回应”写因果链。抬右前臂时可以双脚站稳，袖口随之轻滑，对方看见后才伸手；保持重心稳定也是平衡，不必每次抬手都迈步。没有风或明显运动时不添加大幅飘动。

牵手、戴簪、递玉佩必须确定谁的哪只手、接触哪里、何时握稳或固定、对方怎样接受。交物时接收者承托稳定后递出者再撤手；戴簪时对方稳住头部，簪固定后才松指。触碰与稳定完成是两个状态，不能省略中间的接受。本公开版不设计奇幻大动作。

对话和双人行为优先设计听者、接收者的反应，判断一句话怎样改变他，而不只安排说话者的嘴。无对白段保持无口型，不为显露情绪强加台词。

## 3. 交付格式

每个画面单元填写一张表演卡；分镜完成后补镜号。卡前必填：`内容编号/场号｜镜型（事件/状态）｜本单元实际在做什么｜此刻行动的依据｜必须留下的结果｜来源剧本版本`。多个镜头覆盖同一行为时沿用同一依据，不重复从零起势。

| 单元/镜号 | 起始关系与姿态 | 触发与视线对象 | 主动行为及平衡/随动 | 接收方一至两个反应 | 手与接触过程 | 结束状态与余波 | 可见性要求 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 对应场次 | 填行为发生前状态 | 写实际看见/听见什么 | 写动作链 | 写先后变化 | 无接触写无 | 写如何交给后镜 | 远景可见或需近景 |

填表示例：

> 单元：庭院佩簪；起点：她左手扶发髻，头部稳定，他右手持凤簪；触发：她略低头让出佩戴位置；行动：他站稳后抬右前臂，袖口轻滑，将簪插入发髻侧面；接触：簪固定后右手松开撤回；回应：她放下左手，抬眼停在他脸上；末态：凤簪留在发间，两人视线相接；可见性：至少看清持簪手与她的眼神。

## 4. 交付前自检

1. 事件镜有可见触发、反应与可见选择，次序未倒置；状态镜以持续注视、距离或余韵收束即可，没有硬加的转身或伸手；不符则重写表演或退回剧本。
2. 每镜主要微反应不过载，所需景别能看清；看不见则改表现部位或交分镜调整。
3. 主动部位、平衡、随动与接收方反应构成一条链，没有无因飘动或机械同步；不符则简化动作。
4. 接触写齐人物、左右手、位置、稳定完成和接受，撤手顺序合理；缺项就重写接触过程。
5. 听者有接收过程，无对白约定保持，切镜后的情绪与前镜相接；不符则修关联单元。
6. 表演没有擅自改剧情结果、添加奇幻动作或让每世重复同样反应；越界则退回本场目标。

任一项未通过，改对应表演卡并复核前后单元，再交分镜；文字表演不等于实际自然度已验证。
