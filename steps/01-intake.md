# 01 接手

目标：得到一张能继续制作的需求卡。先阅读用户已给的资料与现有成果，把明确选定的内容留下，只询问影响下一步的缺项。

收集两人的清晰正脸、侧脸及全身照片，记录身高差。照片不足时可以先做文字设计，但人物出图前须补足辨认身份所需的视角，不用陌生脸替代。

填写下表；未定项写“待定”，不要替用户虚构经历或选择。

| 项目 | 填写内容 |
| --- | --- |
| 新人 | 两人的称呼、照片对应关系、身高差 |
| 故事年代 | 想呈现几世，分别在哪个年代；尚未选择的年代 |
| 制作方式 | 全部 AI、部分实拍；已有实拍素材用于哪些段落 |
| 放映要求 | 完整影片目标时长、画面比例、播放场合 |
| 音乐与人声 | 曲目或音频是否已提供；是否需要对白、旁白或纯音乐 |
| 结尾 | 是否落在现代婚礼；希望两人最终呈现什么关系状态 |
| 工具 | 使用的生图和生视频工具，当前可用的多图输入方式 |
| 已定内容 | 人物、年代、故事、服装、场景及已选图片和视频 |
| 本轮任务 | 从哪里接着做；哪些内容明确保留；待补资料 |

年代与制作方式分开判断：现代婚礼可以由 AI 制作，古代段也可能包含实拍。不要由服装或地点推断制作方式。

交付需求卡和简短缺项清单。继续制作时沿用已确认结果；没有必要为恢复进度重新生图或重写全片。
