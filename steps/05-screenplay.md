# 05 剧本

## 1. 输入与停点

必需输入：本次完整或局部写作范围、整片段落顺序、各世世界与关系设定、已定台词及无对白限制。局部改写还需前后相邻段的入场与离场状态。

缺少关系起点、段落任务或影响行为的世界规则时，停对应场次并退回概念或分场。用户已定内容相互矛盾时，列出冲突位置，不能自行覆盖。新人照片、具体模型与未定配乐不阻止写剧本；无音乐时不声称节奏已按实际音轨成立。

## 2. 判断与执行

### 先写每世三行，再写整场戏

每世先写“关系状态、本世的事、交给下一世什么”三行摘要。用户要完整剧本时，三行只作骨架，必须继续展开每个内容段的场次正文，不用一句“温馨互动”代替整场。

按“此刻状态 → 可见触发 → 主动行为 → 对方接收与回应 → 新状态”检查事件。并非每场都要冲突：纯抒情场写两人正在怎样共同活动、观看重点怎样变化、最后停在哪个关系状态，不硬造误会。

| 需要判断的地方 | 可执行标准 | 未达到时的修法 |
| --- | --- | --- |
| 行为动机 | 从场内已知处境可理解为何此刻行动 | 补一个必要的可见触发，不补长篇背景解释 |
| 关系成立 | 对方的接受、拒绝或调整实际出现在正文里 | 把回应写成可见行为，不能只写“他知道她懂了” |
| 信息推进 | 每个内容段增加人物、空间、时代或关系认识 | 删除重复过程，或换有不同结果的内容 |
| 时间省略 | 省略后仍理解动作结果及人物位置 | 保留关键接触与选择，删无信息的准备和等待 |
| 下一段入口 | 前段留下的状态与后段接法一致 | 修段尾或段首；视觉呼应不伪装成连续动作 |

### 让情感存在于行为中

“她感到被理解”不是可拍内容。可写为：她抓紧衣袖，他注意到后把手移到她够得到的位置；她先看手，再将左手放入他掌心，肩膀放松。只有剧情确实需要时才加入对白，已定原句保持；无对白场不新增口型或解释性旁白。

身份变化、信物交接、人物离开或靠近，都须有可理解的过程。代词容易混淆时直接写两人的称呼或左右手。不同世可以相似动作相互呼应，但第二次要增加意义，不能三世都按相同次序牵手、回头、微笑。

### 按整片而非单场检查容量

先通读全部正文，再比较相邻段及各世收束。达到关系结果后，不再连续添加拥抱、对视和离开来重复结束。删减后内容不够目标长度，应补对观看线有贡献的段落并更新分场，不能延长停顿填数。文字估时只判断可疑缺口，实际节奏仍待影像检验。

## 3. 交付格式

先交各世三行摘要，再用以下字段写出本次范围内的每场正文。

| 场次字段 | 必填内容 |
| --- | --- |
| 场号/段号/所属世 | 与分场对应，局部修改保留原编号 |
| 地点/时段/在场人物 | 只写本场会影响观看和行为的信息 |
| 入场状态 | 关系、位置、持物和已知信息 |
| 本场任务 | 观众本场新增什么认识或感受 |
| 连续正文 | 按发生顺序写具体行为、触发与双方回应 |
| 台词或声音 | 实际文字；无对白写无，未定音乐不编造拍点 |
| 离场状态 | 双方姿态、关系结果及道具状态 |
| 下一场衔接 | 连续动作、视觉情绪联系或新章节，写承接对象 |
| 暂估长度 | 来自行为与回应所需时间，不能当实测 |

正文示例：

> 民国照相馆内，两人并肩坐好。她左手拢住袖口，目光停在前方。他侧眼看见她的手，没有催促，把右手掌心朝上放到两人之间。她低头看向他的掌心，松开袖口，将左手放上去；他合拢手指后，她的肩膀落下来。两人交换一次眼神，再一同望向前方。无对白。离场时右手与左手已握稳，下一段若接现代婚礼，按关系呼应处理，不当作同一空间的延续。

局部修订交替换正文及受影响场号，不只交修改建议。表格和正文都由你填完整。

## 4. 交付前自检

1. 本次请求的全部场次都有实际正文，三行摘要没有顶替完整剧本；缺场就退回展开。
2. 关键触发、主动行为及接收方回应可见，理解不依赖创作说明；缺项就重写行为链。
3. 人物位置、知情范围和信物状态前后相容；矛盾则修本场或退回上游设定。
4. 相邻段及跨世没有无意义重复，安静段也能说明观看作用；重复则删并或换内容。
5. 内容能够解释暂估长度，未靠慢放与等待凑数；不够则退回分场补有效内容。
6. 开场到结尾的关系线完整，已定台词与无对白限制保留，结尾没有反复收束；不符则修受影响场次。

任何一项未通过，先改实际正文，再复核前后场；不把剧本缺口推给镜头或音乐。
