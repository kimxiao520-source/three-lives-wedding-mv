# 三生三世 · AI 婚礼 MV

让 AI 按 11 步完成多世婚礼影片的故事设计、资产准备、表演、分镜、视频提示词与返修。

适合同一对新人跨年代的**抒情 MV**，也适合**每世各有故事、彼此呼应的剧情短片**。可以从零开始，或接着已有剧本、照片和回片继续做。世数、年代与时长按作品需要确定。

这是一套 Markdown 创作规则。实际出图、视频生成与剪辑，需要运行环境中可用的工具。

[下载完整文件](https://github.com/kimxiao520-source/three-lives-wedding-mv/archive/refs/heads/main.zip) · [阅读 Skill 入口](SKILL.md) · [查看完整示例](#完整示例)

## 先试一次

把仓库文件提供给 AI 后，可以直接说：

```text
请先读取 SKILL.md，再按对应步骤帮我设计一部三生三世 AI 婚礼短片。
我想让古代、民国和现代各有自己的故事，彼此呼应。
古代从街上偶遇开始，人物行为要合理，关系自然发展。
这轮先交完整概念和分场，暂不做资产、分镜或视频提示词。
我没提供的真实经历，不要替我编成事实。
```

这轮应得到各世内容、人物关系、段落顺序和时长安排。确定故事后，再继续制作；已有成果时，直接说明本轮需要处理的部分。

例如：

```text
沿用我已确认的剧本和现有图片，本轮完成表演、分镜和中文视频提示词。
写清每张参考图的用途，列出实际缺少的材料，分别说明已完成和未执行的工作。
```

## 下载与使用

1. [下载仓库](https://github.com/kimxiao520-source/three-lives-wedding-mv/archive/refs/heads/main.zip)并解压，保留 `SKILL.md`、`steps/` 和 `examples/` 的相对位置。
2. **支持 Skill 的智能体**：将整个文件夹放入客户端支持的 Skills 目录，再按该客户端的方式加载。支持按名称调用时，可使用 `$three-lives-wedding-mv`。
3. **直接对话使用**：提供 `SKILL.md` 和当前步骤需要的文件正文，让 AI 先读入口、再读对应步骤。能读取仓库链接的环境可直接读取；不能读取时，需要上传或粘贴文件。

习惯使用 Git 的话，也可以克隆：

```bash
git clone https://github.com/kimxiao520-source/three-lives-wedding-mv.git
```

完整新作按顺序推进；只改情节、写提示词或检查回片时，从相应步骤继续。

## 11 步入口

| 步骤 | 本步交付 |
| --- | --- |
| [01 接手](steps/01-intake.md) | 恢复已有进度，确定本轮范围与交付物 |
| [02 定片型](steps/02-type.md) | 确定抒情或剧情的组织方式，区分各世内容 |
| [03 概念](steps/03-concept.md) | 各世内容、世界、美术与必要信物设计 |
| [04 分场](steps/04-treatment.md) | 各世段落、先后顺序、衔接与时长安排 |
| [05 剧本](steps/05-screenplay.md) | 完整正文，检查段落贡献、承接与内容容量 |
| [06 资产](steps/06-assets.md) | 白底四宫格人物板、场景套图、道具状态图与完整出图词；按需补首帧 |
| [07 表演](steps/07-acting.md) | 可见的行为、回应或持续状态 |
| [08 分镜](steps/08-shot-plan.md) | 景别、机位、摄影与跨世接点 |
| [09 视频词](steps/09-video-prompt.md) | 素材对应表、逐单元中文提示词与实际执行状态 |
| [10 连续性](steps/10-continuity.md) | 同世衔接、跨世身份和信物状态的核对结果 |
| [11 返修](steps/11-revise.md) | 具体问题、局部修改与完整声画复查 |

每步的输入要求、方法、交付格式和自检都在对应文件中。

## 需要准备什么

| 当前要做的事 | 提供的材料 |
| --- | --- |
| 设计故事 | 想要的感觉、已定年代或情节、必须保留的内容；未定项可先做候选 |
| 制作新人形象与场景 | 已确认的故事、可辨认的身份照片、已有衣装与场景资料 |
| 写视频词并提交生成 | 镜头表、表演要求及对应的实际参考图；缺图时先列缺项 |
| 检查与返修 | 实际回片、对应分镜与提示词；检查声音时提供含音轨的文件 |

人物每人每套衣装使用一张白底四宫格；默认商业美妆质感，选择自然写实时关闭。古代段和重要场景准备同一空间的建立、剧情、氛围三张空景，具体方法见[资产步骤](steps/06-assets.md)。

当前公开版重点处理日常相处与关系接触。文字完成、提交生成和回片可用分别记录；人物是否自然、画面是否连贯、音乐与节奏是否成立，需要检查实际影片。
